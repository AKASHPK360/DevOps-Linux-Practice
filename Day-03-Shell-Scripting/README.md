# Day 03 - Linux Shell Scripting

## Topics Practiced

1. Environment Variables and PATH
2. Output Redirection (>, >>)
3. Shell Scripting and Automation
4. Parent and Child Shells
5. Command Exit Codes ($?)
6. Standard Output (stdout)

## Key Concepts

- Environment variables store information used by processes.
- PATH tells the shell where to search for executable commands.
- `>` redirects output and overwrites a file.
- `>>` appends output to a file.
- `$?` stores the exit status of the last executed command.
- stdout represents standard output (file descriptor 1).
- Child shells inherit exported environment variables from parent shells.

environment variables, redirection, and scripting work.
